# Project Structure

This document explains the directory structure of the Hugo portfolio site.

```
portfolio/
├── .github/              # GitHub Actions workflows
├── archetypes/          # Content templates
├── assets/              # Processed assets (CSS, JS, images)
│   └── css/            # Main CSS (copied from theme)
├── content/            # All site content (Markdown files)
│   ├── about/          # About page content
│   ├── blog/           # Blog posts
│   ├── contact/       # Contact page content
│   ├── projects/      # Portfolio projects
│   │   ├── project-name/
│   │   │   ├── index.md
│   │   │   ├── thumb.jpg
│   │   │   └── *.jpg/png
│   └── tutorials/     # Tutorial content
├── data/               # YAML/JSON data files
│   └── contact.yaml   # Contact info & social links
├── layouts/            # Custom templates (overrides theme)
│   ├── _partials/     # Reusable components
│   ├── projects/     # Project-specific templates
│   └── index.html    # Homepage template
├── public/            # Built site (generated by Hugo)
├── resources/         # Hugo cached resources
├── static/            # Static files (images, fonts, etc.)
│   ├── images/       # Site images (avatar, logos)
│   ├── thumbs/       # Project thumbnails
│   └── talesrt_logo.svg
├── themes/            # Hugo themes
│   └── talesrt/      # Custom theme
│       ├── assets/   # Theme assets (CSS, JS)
│       ├── layouts/  # Theme templates
│       └── static/   # Theme static files
├── hugo.toml          # Main configuration
├── netlify.toml       # Netlify deployment config
└── documentation/     # This documentation
```

## Key Directories

### `content/`

Contains all the site's content in Markdown format. The structure defines the URL:

| Path | URL |
|------|-----|
| `content/about/index.md` | `/about/` |
| `content/contact/_index.md` | `/contact/` |
| `content/projects/glutton/index.md` | `/projects/glutton/` |

### `static/`

Files here are served as-is. Put images, fonts, favicons here.

- `static/images/avatar.png` - Profile picture
- `static/talesrt_logo.svg` - Site logo
- `static/thumbs/` - Project thumbnail images

### `themes/talesrt/`

The custom Hugo theme containing templates and assets.

### `layouts/` (Theme Override)

**Important:** Root `layouts/` automatically overrides files in `themes/talesrt/layouts/`. This is standard Hugo behavior.

Current overrides:
- `layouts/index.html` — custom homepage with procedural grid
- `layouts/projects/single.html` — custom project page

When modifying templates, check `layouts/` (root) first before `themes/talesrt/`.

## Important Files

- **`hugo.toml`** - Main configuration (URL, title, params)
- **`data/contact.yaml`** - Contact info and social media links
- **`content/projects/*/index.md`** - Project definitions with frontmatter
- **`content/projects/*/thumb.jpg`** - Thumbnail for project grid

## Build Output

The `public/` directory is generated by Hugo and contains the final static site. This is what gets deployed to GitHub Pages.

**Do not edit files in `public/` directly** - they will be overwritten on the next build.
